This is the product design concept, packaged as a static website preview.
Generation and replies are simulated; no model, compiler, supplier, account,
or manufacturing service is connected. Drawings are illustrative. Existing
simulation notices, export restrictions, and local-storage notices are retained.

Website-specific modifications:
- src/pages/preview.astro supplies the original HTML shell as a native Astro
  route, adds noindex/nofollow, a base URL, a no-JavaScript fallback, and loads
  preview-bridge.js after app.js. This serves /preview/ in development and builds.
- home.js uses localStorage key synth-website-concept-projects-v1.
- home.js and app.js redirect omitted PDF/gallery links to ../#workspace,
  labeled "About this preview".
- The home footer includes a "Back to Synth" link to ../.
- preview-bridge.js transfers an optional ?idea= value, capped at 2,000
  characters, to the home prompt without submitting it or starting generation.
  It removes the idea query parameter from the URL and focuses the prompt.
  Links without an idea query parameter preserve normal hash navigation.
